Section 01

What is a Function?

A function is a named, reusable block of code that performs a specific task. Instead of repeating the same logic in multiple places, you write it once and call it by name wherever needed. Functions are the primary building block of modular, maintainable programs.

Think of a function like a coffee machine: you put in beans (input), it performs a process, and you get coffee (output). You don't need to understand the internal mechanism every time — you just press the button.

Why functions matter: Code without functions quickly becomes a "wall of text" — hard to read, debug, and modify. Functions enforce the DRY principle: Don't Repeat Yourself.

Core Benefits

BenefitExplanation
ReusabilityWrite once, use many times — no copy-paste errors.
ModularityBreak a large problem into small, solvable pieces.
ReadabilityA well-named function makes code read like English prose.
TestabilityIsolated logic is far easier to unit-test.
AbstractionHide complexity — callers don't care about internals.

Defining Functions

Python uses the def keyword to declare a function, followed by the name, parentheses, a colon, and an indented body.

    return message

Scope & Namespaces

Every variable lives in a scope — the region of the program where it's visible. Python follows the LEGB rule for resolving names.

LetterScopeExample
LLocal — inside the current functionvariables defined inside def
EEnclosing — outer function (closures)nested functions
GGlobal — module-levelx = 10 at top of file
BBuilt-in — Python's built-inslen, print, range
scope.py
Python 
counter = 0   # Global scope

def increment():
    global counter   # Tell Python we mean the global variable
    counter += 1

def make_multiplier(factor):
    # Closure: inner function captures 'factor' from enclosing scope
    def multiply(x):
        return x * factor  # 'factor' is in Enclosing scope
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5))   # 10
print(triple(5))   # 15

Lambda Functions

A lambda is an anonymous, single-expression function. It's useful when you need a small function briefly — commonly passed as an argument to map(), filter(), or sorted().

lambda_examples.py
Python

def square(x): return x ** 2

    {"name": "Bob",   "grade": 95},
    {"name": "Carol", "grade": 72},
]
ranked = sorted(students, key=lambda s: s["grade"], reverse=True)
for s in ranked:
    print(s["name"], s["grade"])   # Bob 95, Alice 88, Carol 72

Rule of thumb: If a lambda becomes complex (multiple conditions, statements), convert it to a named def. Lambdas are for brevity, not power.
Section 07

Decorators

A decorator is a function that wraps another function, adding behaviour before or after it runs — without modifying the original function's code. This is the "open/closed principle" in action.

decorator.py
Python 
import time
import functools

def timer(func):
    """Decorator that measures how long a function takes."""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"[{func.__name__}] ran in {elapsed:.4f}s")
        return result
    return wrapper

@timer
def process_data(n):
    return sum(range(n))

process_data(1_000_000)
# [process_data] ran in 0.0231s

# Common decorators in Python's standard library
from functools import lru_cache

@lru_cache(maxsize=128)
def fibonacci(n):
    if n < 2: return n
    return fibonacci(n-1) + fibonacci(n-2)
Real use: Web frameworks like Flask and FastAPI use decorators extensively — @app.route("/home") is a decorator that registers a URL handler.
Section 08

Recursion

A recursive function calls itself to solve a smaller version of the same problem. Every recursive solution needs a base case (to stop) and a recursive case (to reduce the problem).

recursion.py
Python 
# Classic: Factorial
def factorial(n):
    if n == 0:         # Base case
        return 1
    return n * factorial(n - 1)  # Recursive case

print(factorial(5))   # 120  (5×4×3×2×1)

# Real-world: flatten a nested list of any depth
def flatten(lst):
    result = []
    for item in lst:
        if isinstance(item, list):
            result.extend(flatten(item))  # Recurse into sub-lists
        else:
            result.append(item)
    return result

nested = [1, [2, [3, 4]], [5, [6, [7]]]]
print(flatten(nested))   # [1, 2, 3, 4, 5, 6, 7]
Watch out: Python's default recursion limit is 1000. For deeply nested problems, prefer iteration or increase the limit with sys.setrecursionlimit().
Section 09

Generator Functions

A generator uses yield instead of return. It produces values one at a time, pausing execution between calls — ideal for large datasets that don't fit in memory.

generators.py
Python 
# Reading a huge log file line by line (memory-efficient)
def read_log(filepath):
    with open(filepath) as f:
        for line in f:
            yield line.strip()   # Yield one line at a time

# Infinite sequence generator
def counter(start=0):
    n = start
    while True:
        yield n
        n += 1

gen = counter(10)
print(next(gen))  # 10
print(next(gen))  # 11
print(next(gen))  # 12

# Generator expression (compact syntax)
squares = (x**2 for x in range(1_000_000))  # No memory cost!
print(next(squares))  # 0
Section 10

map(), filter() & sorted() — with Lambda

These three built-in functions are the backbone of functional-style Python. They each accept a function as their first argument — and that is exactly where lambda shines. Instead of defining a throwaway named function, you write the logic inline.

FunctionWhat it doesReturns
map(fn, iter)Apply fn to every element — transform each itemmap object (lazy)
filter(fn, iter)Keep only items where fn returns True — select itemsfilter object (lazy)
sorted(iter, key, reverse)Return a new sorted list — order items by a criterionnew list
Lazy evaluation: map() and filter() return iterator objects — they compute nothing until you consume them (e.g. wrap in list() or loop over). sorted() returns a fully materialised list immediately.
Section 10a

map() — Transform Every Element

map(function, iterable) applies a function to each element and returns a new iterator of results. Think of it as a conveyor belt: every item passes through the same operation.

Syntax

map_syntax.py
Python 
# General form
result = list(map(function, iterable))

# With a named function
def square(x): return x ** 2
list(map(square, [1, 2, 3, 4]))   # [1, 4, 9, 16]

# Same thing with lambda (no need to name the function)
list(map(lambda x: x ** 2, [1, 2, 3, 4]))   # [1, 4, 9, 16]

Section 10b

filter() — Keep Only What Passes the Test

filter(function, iterable) passes each element through a test function. If the function returns True, the element is kept; if False, it is discarded. The result is a filtered iterator.

Syntax

filter_syntax.py
Python 
# General form
result = list(filter(predicate_function, iterable))

# Named function approach
def is_even(n): return n % 2 == 0
list(filter(is_even, [1,2,3,4,5,6]))   # [2, 4, 6]

# Lambda approach — same result, less code
list(filter(lambda n: n % 2 == 0, [1,2,3,4,5,6]))   # [2, 4, 6]

# filter(None, iter) removes all falsy values automatically
list(filter(None, [0, "", 3, None, "hi", False, 7]))   # [3, 'hi', 7]

Section 10c

sorted() — Order by Any Criterion

sorted(iterable, key=None, reverse=False) returns a new sorted list without modifying the original. The key parameter accepts any function — and lambda is the natural fit for extracting a sort field on the fly.

Syntax

sorted_syntax.py
Python 
# Basic — sorts numbers/strings by default ordering
sorted([3, 1, 4, 1, 5])            # [1, 1, 3, 4, 5]
sorted([3, 1, 4], reverse=True)   # [4, 3, 1]

# key= accepts any function
words = ["banana", "fig", "apple", "kiwi"]
sorted(words, key=len)            # ['fig', 'kiwi', 'apple', 'banana']

# lambda as key — sort strings by last character
sorted(words, key=lambda w: w[-1])
# ['banana', 'apple', 'fig', 'kiwi']

# sorted() never modifies the original — .sort() does (in-place, lists only)
original = [3, 1, 2]
new_list = sorted(original)   # original is still [3, 1, 2]

Combining map(), filter() and sorted() — Pipeline Pattern

These three functions compose naturally into a data pipeline — a common pattern in data processing scripts.

pipeline.py
Python 
# Scenario: process raw sales records
# 1. filter  → keep only completed sales
# 2. map     → compute total (qty × unit_price) for each
# 3. sorted  → rank by total descending

sales = [
    {"id": 1, "item": "Laptop",  "qty": 2, "price": 65000, "status": "complete"},
    {"id": 2, "item": "Mouse",   "qty": 5, "price": 950,  "status": "pending"},
    {"id": 3, "item": "Monitor", "qty": 3, "price": 18000, "status": "complete"},
    {"id": 4, "item": "Webcam",  "qty": 1, "price": 3200, "status": "cancelled"},
    {"id": 5, "item": "Keyboard","qty": 4, "price": 1800, "status": "complete"},
]

# Step 1 — filter: completed only
completed = filter(lambda s: s["status"] == "complete", sales)

# Step 2 — map: add a "total" field to each record
with_totals = map(
    lambda s: {**s, "total": s["qty"] * s["price"]},
    completed
)

# Step 3 — sorted: highest total first
report = sorted(with_totals, key=lambda s: s["total"], reverse=True)

print(f"{'Item':12} {'Qty':5} {'Unit':8} {'Total'}")
print("─" * 38)
for s in report:
    print(f"{s['item']:12} {s['qty']:5} ¥{s['price']:7} ¥{s['total']}")
# Laptop       2     ¥65000  ¥130000
# Monitor      3     ¥18000  ¥54000
# Keyboard     4     ¥1800   ¥7200
Key insight — pipeline composability: filter(), map(), and sorted() each accept an iterable and return one — so the output of one flows directly into the next. This is the functional programming style: no intermediate lists, no mutation, pure data transformation.

Finance / Banking
EMI Calculator for a Loan

Banks use this formula every time someone applies for a loan. Given principal, annual interest rate, and tenure in months — compute the monthly EMI (Equated Monthly Instalment).

emi_calculator.py
Python 
def calculate_emi(principal: float, annual_rate: float, months: int) -> float:
    """
    Calculate the monthly EMI for a loan.

    Args:
        principal:    Loan amount in currency units
        annual_rate:  Annual interest rate as a percentage (e.g. 8.5)
        months:       Loan tenure in months

    Returns:
        Monthly EMI amount, rounded to 2 decimal places
    """
    r = (annual_rate / 100) / 12   # Monthly interest rate
    if r == 0:                      # Zero-interest loan edge case
        return round(principal / months, 2)
    emi = principal * r * (1 + r)**months / ((1 + r)**months - 1)
    return round(emi, 2)

def loan_summary(principal, annual_rate, months):
    """Print a full loan repayment summary."""
    emi  = calculate_emi(principal, annual_rate, months)
    total_paid     = round(emi * months, 2)
    total_interest = round(total_paid - principal, 2)

    print(f"── Loan Summary ──────────────────")
    print(f"Principal:       ₹{principal:>12,.2f}")
    print(f"Annual Rate:     {annual_rate}%")
    print(f"Tenure:          {months} months ({months//12} years)")
    print(f"Monthly EMI:     ₹{emi:>12,.2f}")
    print(f"Total Paid:      ₹{total_paid:>12,.2f}")
    print(f"Total Interest:  ₹{total_interest:>12,.2f}")

loan_summary(500_000, 8.5, 60)
# Monthly EMI: ₹10,228.17  |  Total Interest: ₹113,690.20

E-Commerce / Retail
Shopping Cart with Discount Engine

E-commerce platforms apply multiple discount rules (coupons, bulk discounts, loyalty tiers). Functions keep each rule isolated and composable.

cart.py
Python 
def calculate_subtotal(cart: list) -> float:
    return sum(item["price"] * item["qty"] for item in cart)

def apply_coupon(subtotal: float, code: str) -> float:
    coupons = {"SAVE10": 0.10, "SAVE20": 0.20, "WELCOME": 0.15}
    discount = coupons.get(code.upper(), 0)
    return subtotal * (1 - discount)

def apply_bulk_discount(subtotal: float) -> float:
    # 5% off orders over ₹2000
    return subtotal * 0.95 if subtotal > 2000 else subtotal

def add_tax(amount: float, rate: float = 0.18) -> float:
    return round(amount * (1 + rate), 2)

def checkout(cart, coupon=""):
    """Run the full checkout pipeline."""
    subtotal = calculate_subtotal(cart)
    after_coupon = apply_coupon(subtotal, coupon)
    after_bulk   = apply_bulk_discount(after_coupon)
    total        = add_tax(after_bulk)
    print(f"Subtotal: ₹{subtotal:.2f} → Final (incl. GST): ₹{total:.2f}")
    return total

cart = [
    {"name": "Headphones", "price": 1500, "qty": 1},
    {"name": "USB Cable",   "price": 250,  "qty": 2},
]
checkout(cart, coupon="SAVE10")
# Subtotal: ₹2000.00 → Final (incl. GST): ₹2239.20

Student Grade Analysis System

Schools and universities need to process large student datasets — computing statistics, assigning grades, and flagging at-risk students.

grades.py
Python 
def letter_grade(score: float) -> str:
    if   score >= 90: return "A"
    elif score >= 80: return "B"
    elif score >= 70: return "C"
    elif score >= 60: return "D"
    else:            return "F"

def class_statistics(scores: list) -> dict:
    """Compute descriptive statistics for a list of scores."""
    n = len(scores)
    avg = sum(scores) / n
    sorted_scores = sorted(scores)
    median = sorted_scores[n // 2] if n % 2 else \
             (sorted_scores[n//2-1] + sorted_scores[n//2]) / 2
    variance  = sum((x - avg)**2 for x in scores) / n
    std_dev   = variance ** 0.5
    return {
        "count": n, "mean": round(avg, 2),
        "median": median, "std_dev": round(std_dev, 2),
        "highest": max(scores), "lowest": min(scores)
    }

def flag_at_risk(students: list, threshold: float = 60) -> list:
    return [s for s in students if s["score"] < threshold]

Password Strength Validator

Every app that handles user accounts needs to enforce password policies. Functions let each rule be tested independently.

password.py
Python 
import re

def has_minimum_length(pwd, min_len=8) -> bool:
    return len(pwd) >= min_len

def has_uppercase(pwd) -> bool:
    return bool(re.search(r"[A-Z]", pwd))

def has_digit(pwd) -> bool:
    return bool(re.search(r"\d", pwd))

def has_special_char(pwd) -> bool:
    return bool(re.search(r"[!@#$%^&*(),.?\":{}|<>]", pwd))

def validate_password(pwd: str) -> dict:
    """Return a report of which rules pass/fail."""
    rules = {
        "min_length":   has_minimum_length(pwd),
        "uppercase":    has_uppercase(pwd),
        "digit":        has_digit(pwd),
        "special_char": has_special_char(pwd),
    }
    passed  = sum(rules.values())
    strength = ["Very Weak", "Weak", "Fair", "Strong", "Very Strong"][passed]
    return {"rules": rules, "strength": strength, "valid": passed == 4}

result = validate_password("MyPass@99")
print(result)
# {'rules': {all True}, 'strength': 'Very Strong', 'valid': True}

Inventory Reorder Alert System

Warehouses need to automatically detect low-stock items and generate reorder lists. A generator-based solution handles large inventories without loading everything into memory.

inventory.py
Python 
def low_stock_items(inventory: list, threshold: int = 10):
    """Generator that yields items below the reorder threshold."""
    for item in inventory:
        if item["stock"] < threshold:
            yield item

def generate_reorder_list(inventory, threshold=10, reorder_qty=50):
    """Return purchase orders for all low-stock items."""
    orders = []
    for item in low_stock_items(inventory, threshold):
        order_qty = reorder_qty - item["stock"]
        orders.append({
            "sku":      item["sku"],
            "name":     item["name"],
            "current":  item["stock"],
            "order":    order_qty,
            "cost":     round(order_qty * item["unit_price"], 2)
        })
    return orders

inventory = [
    {"sku": "A01", "name": "Pencils", "stock": 3,  "unit_price": 0.5},
    {"sku": "B02", "name": "Notepads", "stock": 50, "unit_price": 2.0},
    {"sku": "C03", "name": "Markers", "stock": 7,  "unit_price": 1.5},
]
orders = generate_reorder_list(inventory)
for o in orders:
    print(f"Order {o['order']} × {o['name']} (₹{o['cost']})")
Section 12

Best Practices

✅ Do

Write functions that do one thing only (Single Responsibility Principle). If your function name contains "and", it probably does too much.
Add type hints: def add(a: int, b: int) -> int. They serve as built-in documentation and enable static analysis tools.
Write a docstring for every non-trivial function. Use Google or NumPy style. Your future self will thank you.
Use guard clauses (early returns) to reduce nesting depth and make the "happy path" obvious.

❌ Avoid

Mutable default arguments: def f(lst=[]) is a famous Python gotcha. The list is shared across all calls. Use None instead and initialise inside the body.
Side effects without warning: a function named get_user() should not also delete records. Surprise side effects are the top source of bugs.
Functions longer than ~30 lines: this is a smell. Break them up into smaller, named helpers.
Global state mutation: functions that modify global variables are hard to test and reason about. Prefer returning new values.
